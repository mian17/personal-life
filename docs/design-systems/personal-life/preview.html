Buttons

Every variant is a text or fill treatment; destructive actions are borderless text buttons. Sizes: default 48px tall, bare compact, icon 48px square. Icon buttons are 40px.

A primary fill measures 3.16:1 white-on-accent in dark and 4.50:1 in light; the accent-fill pairing is the repo's frozen token pair, so keep primary labels bold.
